# 背景クラス README

## 概要
ゲーム背景の描画および移動処理に関するコンポーネントクラスが定義されています。背景はゲーム全体で1つだけ生成され、常駐オブジェクトとしてゲームシーンの背景表示に使用されます。

## 主な構成
- コンポジットクラス: `main.py` にて `背景生成()` により生成される
- 格納先: `main.DB.obj背景`
- 使用場所: `描画コントローラ(P描画.py)` にて定期的に描画処理が呼び出される

## 背景オブジェクトの生成タイミング
背景は `/main/main.py` 内でゲーム起動時に1度だけ生成されます。
```python
from   背景             import 背景生成

#≫背景を生成する
main.DB.obj背景 = 背景生成()
```

このため、背景は特定のシーンや出現プロセスによって生成されるのではなく、ゲーム全体の準備フェーズで初期化されます。

## 要素クラス構成

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | 背景のスクロール処理を行う。 |
| FN描画     | ×          | ×          | 背景の描画処理を行う。 |

## 関連クラス
- `main.DB.obj背景`：背景のグローバルオブジェクトとして管理
- `/描画コントローラ/P描画.py`：背景の描画処理呼び出し
- `/背景/` 以下に定義された `FN移動.py`, `FN描画.py`：背景の挙動を担当

---

背景はシーンやキャラクタとは独立して、ゲーム全体にわたって動作する特殊な常駐型オブジェクトです。
