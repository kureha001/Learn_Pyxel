# 終了画面シーン README

## 概要
`/シーン/終了画面/` は、ゲームの終了後に表示されるシーンです。ゲームオーバー時に遷移し、プレイ結果を表示しながら次の操作（タイトル画面への戻りなど）を待ち受けます。

## 主な構成
- コンポジットクラス: `/シーン/終了画面/main.py`
- 格納先: `main.DB.objシーン["終了画面"]`
- シーン制御: `/main/main.py` の `初期化_処理セット()` により生成

## 要素クラス構成

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | 表示継続時間の管理およびユーザー入力の受付を行い、タイトル画面への遷移トリガーを担当する。 |
| FN描画     | ×          | ×          | ゲーム終了の演出や最終スコア、メッセージを画面に表示する。 |

## 関連クラス
- `main.DB.objシーン["終了画面"]`：終了シーンのインスタンスを保持
- `/main/main.py`：シーンの遷移管理
- `main.DB.obj自機共通`：最終スコアなどの取得に使用
- `/更新コントローラ/`：このシーンの FN移動, FN描画 を処理対象に含む
