# タイトル画面シーン README

## 概要
`/シーン/タイトル画面/` は、ゲーム開始時に表示されるシーンであり、スタート入力受付や初期化処理を行います。プレイヤーの操作によってゲーム本編（プレイ画面）へ遷移する役割を担います。

## 主な構成
- コンポジットクラス: `/シーン/タイトル画面/main.py`
- 格納先: `main.DB.objシーン["タイトル画面"]`
- シーン制御: `/main/main.py` の `初期化_処理セット()` により生成

## 要素クラス構成

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ×          | タイトル画面でのキー入力を処理し、ゲーム開始時にシーン遷移を実行。自機共通オブジェクトなどの初期化も行う。 |
| FN描画     | ×          | ×          | タイトル画面の文字列などを画面に描画する処理を行う。 |

## 関連クラス
- `main.DB.objシーン["タイトル画面"]`：このシーンのインスタンスを格納
- `/main/main.py`：全体のシーン初期化と切り替え制御
- `/キャラクタ/自機/自機共通.py`：シーン移行時に初期化されるオブジェクト
