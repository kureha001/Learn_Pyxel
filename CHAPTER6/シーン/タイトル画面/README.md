# タイトル画面シーン README

## 概要
`/シーン/タイトル画面/` は、ゲーム開始時に表示されるシーンであり、スタート入力受付や初期化処理を行います。プレイヤーの操作によってゲーム本編（プレイ画面）へ遷移する役割を担います。

## 主な構成
- コンポジットクラス: `/シーン/タイトル画面/main.py`
- 格納先: `main.DB.objシーン["タイトル画面"]`
- シーン制御: `/main/main.py` の `初期化_処理セット()` により生成
