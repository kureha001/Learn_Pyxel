# プレイ画面シーン README

## 概要
`/シーン/プレイ画面/` は、ゲーム中のメインプレイを制御するシーンであり、自機の操作、敵機の出現、弾の発射、スコアやシールドの管理など、ゲーム進行の核となる処理を統括します。

## 主な構成
- コンポジットクラス: `/シーン/プレイ画面/main.py`
- 格納先: `main.DB.objシーン["プレイ画面"]`
- シーン制御: `/main/main.py` の `初期化_処理セット()` により生成

## 関連クラス
- `main.DB.objシーン["プレイ画面"]`：このシーンのインスタンスを格納
- `/main/main.py`：シーンの生成と遷移制御
- `main.DB.obj自機共通`：スコア・シールド情報の管理オブジェクト
- `main.DB.obj特殊効果`：プレイ中に発動している効果の制御
- 各出現・発射・移動・衝突プロセス：ゲーム進行中にこのシーンで動作する
