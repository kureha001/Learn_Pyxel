# 弾 コンポーネントクラス概要

## 概要
プレイヤーの自機を表現する。

## 格納先コンテナ
自機・敵機(通常敵・ボス)オブジェクトでコンテナを分ける。
| コンテナ　　| 説明　　　　　　　 |
|-------------|--------------------|
| obj弾_自機[]|プレイヤ１・２で共有|
| obj弾_敵機[]|通常敵・ボスで共有　|

## ライフサイクル
| タイミング | 説明　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
|------------|----------------------------------------------------------------|
| 生成     　|移動プロセス(タイトル画面)で、プレイヤー数を選択した際　　　　　|
| 生存中　　 |移動プロセスで画面座標を移動　　　　　　　　　　　　　　　　　　|
|　　　　　　|衝突プロセスでダメージ　　　　　　　　　　　　　　　　　　　　　|
|　　　　　　|発射プロセスで弾発射　　　　　　　　　　　　　　　　　　　　　　|
|　　　　　　|描画プロセスで画面表示　　　　　　　　　　　　　　　　　　　　　|
| 削除   　　|衝突プロセスでなにかと衝突した際　　　　　　　　　　　　　　　　|
| 　　   　　|移動プロセスで終了画面が終了した際(全オジェクト)　　　　　　　　|
| 　　   　　|移動プロセス(終了画面)が次のシーンに遷移する際(コンテナをクリア)|

## 要素クラス
| クラス | 有無 | 概要　　　　　　　　　　　　 |
|--------|------|------------------------------|
| FN移動 |　○　|画面座標を移動　　　　　　　　|
| FN衝突 |　○　|シールド・ダメージ、爆発、削除|
| FN発射 |　○　|弾を発射する　　　　　　　　　|
| FN描画 |　○　|画面に描画　　　　　　　　　　|

|--------|------|------|
| 本体   |  ○  |  ○  | 
| FN移動 |　○　|　－　| 
| FN衝突 |  －  |　－　|
| FN描画 |　○　|　－　|
