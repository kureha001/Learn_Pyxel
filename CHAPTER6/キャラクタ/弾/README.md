# 弾 コンポーネントクラス概要

## 概要
プレイヤーの自機を表現する。

## 格納先コンテナ
自機・敵機別にコンテナを分ける。
| コンテナ 　　| 説明　　　　　　　  |
|--------------|---------------------|
| obj弾_自機[] |プレイヤ１・２で共有 |
| obj弾_敵機[] |通常敵・ボスで共有　 |

## ライフサイクル
| タイミング | プロセス | 説明　　　　　　　　　　　　　　　　　　　　　　　 |
|------------|----------|----------------------------------------------------|
| 生成     　| 移動　　 | タイトル画面で、プレイヤー数を選択した際に生成 　　|
| 生存中　　 | 移動　　 | クラス構造の概要を参照→　　　　　　　　　　　　　 |
| 　　　　　 | 衝突　　 | クラス構造の概要を参照→　　　　　　　　　　　　　 |
| 　　　　　 | 描画　　 | クラス構造の概要を参照→　　　　　　　　　　　　　 |
| 削除   　　| 衝突　　 | なにかと衝突した際に削除　　　　　　　　　　　　　 |
| 　　   　　| 移動　　 | 終了画面が次のシーンに遷移する際にコンテナをクリア |

## クラス構造
| クラス | 有無 | 概要　　　　　 |
|--------|------|----------------|
| FN移動 |　○　| 画面座標を移動 |
| FN衝突 |　○　| 爆発＆削除　　 |
| FN描画 |　○　| 画面に描画　　 |

|--------|------|------|
