# 弾クラス - FN移動 要素クラス README

## 概要
このクラスは、弾の移動処理を司る要素クラスです。弾は自機または敵機の `FN発射` クラスから生成されたのち、この `FN移動` クラスにより毎フレーム位置が更新されます。

## 主な責務
- 弾の移動速度と方向に基づく位置の更新
- 移動限界を超えた場合の自動消去（例: 画面外に出た弾の破棄）

## 特徴
- 弾の進行方向および速度は、弾の生成時に指定される
- `情報クラス` を保持しており、現在位置などの状態管理を行う
- `仕様クラス` は存在しない（移動処理に特化しており、静的仕様は不要）

## 使用される主な属性・処理
- `self.情報.X座標` / `Y座標`：現在位置の座標値
- `self.情報.速度X` / `速度Y`：移動に使用される速度ベクトル
- 画面外判定：指定範囲外に移動した弾は、自動で削除対象となる

## 関連処理
- `main.DB.obj自機` または `main.DB.obj敵機` が格納先となる
- `更新コントローラ / P移動.py` から定期的に呼び出される
- 弾の `FN衝突` や `FN描画` と連携して機能する

## 関連ファイル
- `/キャラクタ/弾/FN移動.py`：当該要素クラスの定義
- `/キャラクタ/弾/情報.py`：弾の動的情報を保持するクラス
- `/更新コントローラ/P移動/`：このクラスの実行をトリガーとするプロセス群

---

このクラスは、弾のライフサイクルにおいて非常に重要な役割を担っており、適切な挙動と破棄処理によって、ゲームの動作安定性を保っています。
