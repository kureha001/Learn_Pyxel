# 自機 コンポーネントクラス概要

## 概要
プレイヤー間で共通利用される自機の情報を一元管理するデータ(仕様・情報)のクラスです。

## 格納先コンテナ
| コンテナ 　 | 説明　　　　　　 |
|-------------|------------------|
| obj自機共通 | 単一オブジェクト |

| タイミング | プロセス | 説明　　　　　　　　　　　　　　　　　　　　　 |

| 生存中　　 | －　　 　| －　　　　　　　　　　　　　　　　　　　　　　 |
