# 自機 コンポーネントクラス概要

## 概要
プレイヤー間で共通利用される自機の情報を一元管理するデータ(仕様・情報)のクラスです。

## 格納先コンテナ
| コンテナ 　| 説明　　　　　 |
|------------|----------------|
| obj自機共通|単一オブジェクト|

## ライフサイクル
| タイミング | 説明　　　　　　　　　　　　　　　　　　　　　　　　 |
|------------|------------------------------------------------------|
| 生成     　|移動プロセス(スタート画面)で、プレイヤー数を選択した際|
| 生存中　　 |移動プロセスで画面座標を移動　　　　　　　　　　　　　|
|　　　　　　|描画プロセスで画面表示　　　　　　　　　　　　　　　　|
| 削除   　　|生成後は常に存在する　　　　　　　　　　　　　　　　　|
