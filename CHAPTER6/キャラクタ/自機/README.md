# 自機 コンポーネントクラス概要

## コンポジットクラス
- **ファイル**: `/キャラクタ/自機/main.py`
- **主な役割**: プレイヤー操作に対応し、複数の要素クラスを統括。

## 要素クラス

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | プレイヤーの移動制御ロジック。入力を元に位置を更新。 |
| FN衝突     | ×          | ×          | 敵や弾との当たり判定を処理。 |
| FN発射     | ×          | ×          | 自弾の生成と発射処理。 |
| FN描画     | ×          | ×          | 画面への表示処理。 |

## データ構造
- 仕様クラス：`仕様クラス`
- 情報クラス：`情報クラス`
