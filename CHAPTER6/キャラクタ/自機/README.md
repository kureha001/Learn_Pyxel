# 自機 コンポーネントクラス概要

## 概要
自機を表現する。

## 格納先コンテナ
| コンテナ　| 説明　　　　　　　　　　　　　　 　|
|-----------|------------------------------------|
| obj自機[] | プレイヤ１・２のオブジェクトで共有 |

## ライフサイクル
| タイミング | プロセス | 説明　　　　　　　　　　　　　　　　　　　　　 　|
|------------|----------|--------------------------------------------------|
| 生成     　| 移動　　 | スタート画面プレイヤー数を選択した際に生成　　　 |
| 生存中　　 | 移動　　 | クラス構造の概要を参照→　　　　　　　　　　　　 |
| 　　　　　 | 衝突　　 | クラス構造の概要を参照→　　　　　　　　　　　　 |
| 　　　　　 | 発射　　 | クラス構造の概要を参照→　　　　　　　　　　　　 |
| 　　　　　 | 描画　　 | クラス構造の概要を参照→　　　　　　　　　　　　 |
| 削除   　　| 移動　　 | プレイ画面でシールド切れの場合にコンテナをクリア |

## クラス構造
| クラス | 有無 | 概要　　　　　　　 |
|--------|------|--------------------|
| FN移動 |　○　| 画面座標を移動　　 |
| FN衝突 |　○　| シールド・ダメージ |
| FN発射 |　○　| 弾を発射する　　　 |
| FN描画 |　○　| 画面に描画　　　　 |

## データ構造
複数プレイヤで共通する仕様は、敵機共通オブジェクトに格納する。
| クラス | 仕様 | 情報 |
|--------|------|------|
| 本体   |　○  |　○　| 
| FN移動 |　－　|　－　| 
| FN衝突 |　－　|　－　| 
| FN発射 |　－　|　－　|
| FN描画 |　－　|　－　|
