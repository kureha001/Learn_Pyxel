# 爆発 コンポーネントクラス概要

## コンポジットクラス
- **ファイル**: `/キャラクタ/爆発/main.py`
- **主な役割**: 衝突や破壊後の演出処理として生成される。

## 要素クラス

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | 爆発の広がりやアニメーション進行。 |
| FN描画     | ×          | ×          | 爆発スプライトの描画処理。 |

## データ構造
- 仕様クラス：`仕様クラス`
- 情報クラス：`情報クラス`
