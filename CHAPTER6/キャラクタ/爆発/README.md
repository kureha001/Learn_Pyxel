# 爆発 コンポーネントクラス概要

## 概要
爆発エフェクトを画面に表現する。

## 格納先コンテナ
| コンテナ　　| 説明　　　　　　　　　　　　　　　　　　　　　　　 |
|-------------|----------------------------------------------------|
| obj弾_爆発[]|自機・通常敵・ボス・弾(自機・敵機)オブジェクトで共有|

## ライフサイクル
| タイミング | 説明　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
|------------|----------------------------------------------------------------|
| 生成     　|衝突プロセスで、自機・敵機・弾が衝突する際　　　　　　　　　　　|
| 生存中　　 |移動プロセスで徐々に巨大化　　　　　　　　　　　　　　　　　　　|
|　　　　　　|描画プロセスで画面表示　　　　　　　　　　　　　　　　　　　　　|
| 削除   　　|移動プロセスで最大化した場合　　　　　　　　　　　　　　　　　　|
| 　　   　　|移動プロセス(終了画面)が次のシーンに遷移する際(コンテナをクリア)|

## 要素クラス
| クラス | 有無 | 概要　　　　　　　　　　　　　　　　 |
|--------|------|--------------------------------------|
| FN移動 |　○　|画面座標を移動、最大化で削除(ボス除く)|
| FN衝突 |　－　|　　　　　　　　　　　　　　　　　　　|
| FN発射 |　－　|　　　　　　　　　　　　　　　　　　　|
| FN描画 |　○　|画面に描画　　　　　　　　　　　　　　|

## データ構造
| クラス | 仕様 | 情報 |
|--------|------|------|
| 本体   |　－　|　○　| 
| FN移動 |  ○  |　－　|
| FN描画 |　－　|　－　|
