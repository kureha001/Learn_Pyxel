# 敵機 コンポーネントクラス概要

## コンポジットクラス
- **ファイル**: `/キャラクタ/敵機/main.py`
- **主な役割**: 出現処理により生成され、行動パターンに応じて制御される。

## 要素クラス

| クラス   | 説明         |
|----------|--------------|
| FN移動   | 自動移動ロジック（ルート定義などに基づく）        |
| FN衝突   | 自機や弾との衝突判定。                            |
| FN発射   | 弾の発射処理。                                   |
| FN描画   | 敵のグラフィック描画処理。                       |

## データ構造
- 仕様クラス：`仕様クラス`
- 情報クラス：`情報クラス`
