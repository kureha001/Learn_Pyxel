# 敵機 コンポーネントクラス概要

## コンポジットクラス
- **ファイル**: `/キャラクタ/敵機/main.py`
- **主な役割**: 出現処理により生成され、行動パターンに応じて制御される。

## 要素クラス

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | 自律的な移動ロジック。種類により軌道が異なる。 |
| FN衝突     | ×          | ×          | 自機や弾との接触を検出。 |
| FN発射     | ×          | ×          | 弾を発射するロジック。種類によって弾のパターンが異なる。 |
| FN描画     | ×          | ×          | 画面への表示処理。 |

## データ構造
- 仕様クラス：`仕様クラス`
- 情報クラス：`情報クラス`
