# キャラクタ管理 全体概要

このドキュメントは、ゲーム内の各キャラクタ（自機・敵機・弾・爆発）の設計方針、構造、およびデータ登録方法の全体像をまとめたものです。

## 構造概要

各キャラクタは「コンポジットクラス」と複数の「要素クラス」により構成されており、主に以下のような役割を担っています。

- **コンポジットクラス**：`main.py` に定義。キャラクタ全体の制御を担い、各要素クラスを包含。
- **要素クラス**：キャラクタの動作に対応するコンポーネント（移動・衝突・発射・描画など）。

## 要素クラス構成（プロセス順）

| カテゴリ | 移動 | 衝突 | 発射 | 描画 |
|----------|------|------|------|------|
| 自機     | ✅ FN移動 | ✅ FN衝突 | ✅ FN発射 | ✅ FN描画 |
| 敵機     | ✅ FN移動 | ✅ FN衝突 | ✅ FN発射 | ✅ FN描画 |
| 弾       | ✅ FN移動 | ✅ FN衝突 | - | ✅ FN描画 |
| 爆発     | ✅ FN移動 | - | - | ✅ FN描画 |

## データ構造

- 各コンポーネントクラスは、以下のように静的・動的データを分離して管理します。

| クラス       | 仕様クラス | 情報クラス |
|--------------|------------|------------|
| 自機         | ✅         | ✅         |
| 敵機         | ✅         | ✅         |
| 弾           | ✅         | ✅         |
| 爆発         | ✅         | ✅         |

## オブジェクトの登録先

キャラクタ生成後のオブジェクト登録先（main.DB.obj〇〇）は、以下の通りです。

| カテゴリ | 登録先 | 分岐条件 |
|----------|--------|----------|
| 自機     | obj自機 | 固定     |
| 敵機     | obj敵機 or objアイテム | アイテム区分により分岐 |
| 弾       | obj弾_自機 / obj弾_敵機 | 所有者IDによる分岐 |
| 爆発     | obj爆発 | 固定     |
