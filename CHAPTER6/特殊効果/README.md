# 特殊効果クラス README

## 概要
特殊効果クラスは、ゲーム内でプレイヤーが取得するアイテムによって発動する効果（例：無敵・スピードアップなど）を管理します。  
本クラスは、アイテム取得時の効果発動および、効果の持続処理を担当します。

## クラス構成

- コンポジットクラス:
  - `class 本体` として定義
- コンテナ:
  - `main.DB.obj特殊効果`
- 仕様クラス:
  - `/特殊効果/仕様.py`
- 情報クラス:
  - `/特殊効果/情報.py`

## 格納先（生成処理）

- ゲーム初期化時に `/main/main.py` にて次のように生成されます：

```python
from 特殊効果 import 特殊効果生成
main.DB.obj特殊効果 = 特殊効果生成()
```

## 関連処理（他クラスとの連携）

| 使用箇所 | 用途 | 備考 |
|----------|------|------|
| `/main/更新コントローラ/P出現/P特殊.py` | アイテム抽選時に発動中の効果を参照（重複防止） | `.情報.発動中` を参照 |
| `/main/更新コントローラ/P衝突/Pアクション.py` | アイテム衝突時に効果を発動 | `.FN衝突.実行()` を呼び出し |
| `/main/更新コントローラ/P移動/main.py` | 効果の持続時間を管理 | `.FN移動.実行()` により時間カウント |
| `/キャラクタ/自機/FN移動.py` | プレイヤーの移動時に効果の影響を参照 | `.情報` を直接参照 |

## 要素クラス構成

| 要素クラス | 仕様クラス | 情報クラス | 説明 |
|------------|------------|------------|------|
| FN移動     | ×          | ○          | 効果の持続時間処理（カウントダウン） |
| FN衝突     | ×          | ×          | アイテム取得時に効果を発動 |

## 備考

- 特殊効果は、通常のキャラクタとは異なり、エンティティオブジェクトではなく1インスタンスのみを `main.DB.obj特殊効果` に常駐させる構成です。
- 出現処理でのアイテム選出や、衝突処理、移動処理など多岐に渡って他モジュールから参照されます。
- 発動中の効果とその状態は `.情報.発動中` にて管理されており、他のロジックでこれを元に処理制御を行います。
